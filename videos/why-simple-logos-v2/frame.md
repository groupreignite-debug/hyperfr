# frame.md — Reignite Group editorial system

canvas: "#1A1A1A"

## Palette
| role | value | use |
| --- | --- | --- |
| canvas | #1A1A1A | every ground |
| ink | #F5F1EA | headlines, logos (Nike / Apple) |
| ink-muted | rgba(245,241,234,0.55) | secondary lines, labels |
| hairline | rgba(245,241,234,0.10–0.22) | grid, construction lines |
| accent | #FF4D1A | key words, underlines, guides, indicators |
| gold | #FFB000 | McDonald's arches + one swatch only |

## Type
- Arabic display: Noto Kufi Arabic 800/900 — headlines 72–120px, line-height 1.35, `dir="rtl"`.
- Arabic support: IBM Plex Sans Arabic 500/600 — 40–52px.
- Latin labels: Inter 600–800, uppercase, letter-spacing 0.2em, 22–26px (SIMPLE, SCALABLE …).

## Composition
- Safe zone: x 90–990, y 300–1500. Header row at y 236.
- Ground: charcoal + 90px hairline grid (≈4% ink), corner crop marks, slow vertical grid drift.
- One idea per beat. Words land on the voice; important words turn orange.
- Motion: expo/power ease-outs, mask reveals, line draws, scale transitions. No spins, glitches,
  flashes, 3D.
